# Pulse prototype — built site

Compiled output of the Pulse field-collections **prototype**, served on GitHub Pages:
https://kaustubhshirsath.github.io/pulse-prototype/

It runs entirely in the browser on dummy data — it never calls a backend. There is no source code here; this
repository only holds the build. Sign-in is simulated (no SSO); every customer, loan and amount is fake.
